# 💰 SpendSense — Smart Expense Analyzer

### Track your expenses. Understand your spending. Manage your budget.

SpendSense is a Python-based personal expense management and
analytics application developed as a mini-project for
Python Programming, Concepts and Applications (PPCA).

It allows users to record expenses, categorize transactions,
monitor budgets, visualize spending patterns, and analyze
financial activity using an interactive dashboard.

## 🎯 Objectives

- Develop a practical Python application.
- Demonstrate object-oriented programming.
- Apply file handling and exception handling.
- Perform numerical calculations using NumPy.
- Analyze tabular data using Pandas.
- Visualize financial information using Matplotlib.
- Build an interactive interface using Streamlit.

## ✨ Features

- Add, edit, and delete expenses.
- Categorize expenses by type.
- View monthly spending statistics.
- Monitor budget utilization.
- Receive budget threshold alerts.
- Visualize category-wise expenses.
- Compare monthly spending.
- Filter transactions by category and amount.
- Analyze expenses within a selected date range.
- Export expense records as CSV files.
- Save budget settings between sessions.
- Load sample data for demonstrations.

## 🚀 Installation

### 1. Clone the repository

    git clone https://github.com/AaliyanShaikh/SpendSense.git

### 2. Open the project folder

    cd SpendSense

### 3. Install the dependencies

    python -m pip install -r requirements.txt

### 4. Run the application

    streamlit run app.py

The application will open in your browser.

## 🧪 How to Use

1. Open the Dashboard.
2. Add an expense with its amount, date, and category.
3. View updated spending statistics.
4. Filter or edit records in View Expenses.
5. Explore charts in Analytics.
6. Set your budget in Budget Manager.
7. Export expense data when required.
